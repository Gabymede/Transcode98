# Transcode 98

Минималистичный GUI для FFmpeg.
Перекодирует видео в AV1 / VP9 / HEVC [libx265] с возможностью задать целевой размер файла.
Этот проект на 99% состоит из кода DeepSeek. Остальной 1% произведен мною. Дизайн интерфейса, подбор кодеков и параметров транскода.

## Возможности

- Кодеки: AV1 (libsvtav1), VP9 (libvpx-vp9), HEVC (libx265)
- Два режима качества: фиксированный битрейт/CRF либо целевой размер файла задаваемый в МегаБайтах
- Одно- и двупроходное кодирование
- Прогресс в строке заголовка, на панели задач и в статус-баре
- Drag & drop файлов, вставка из буфера обмена (Ctrl+V)
- После успешного кодирования исходник можно автоматически переместить в `old_material/`, которая автоматически создается в директории нахождения исходника
- Быстрый анализ данных файла через ffprobe

## Особенности и параметры кодирования

Программа использует программные (CPU) энкодеры FFmpeg для достижения наилучшего качества сжатия.

### AV1 (libsvtav1)
- **Режим:** VBR (переменный битрейт) или целевой размер файла.
- **Пресеты:** 4 для однопрохода, 8 (анализ) и 2 (финал) для двухпрохода. 
- **GOP (Keyframe interval):** 30 кадров.
- **Пиксельный формат:** yuv420p.
- **Аудио:** Копируется без перекодирования (copy).

### VP9 (libvpx-vp9)
- **Режим:** VBR с жестким ограничением (maxrate и bufsize 24M).
- **Оптимизация:** Включен многопоточный анализ рядов (row-mt 1), разделение на колонки (tile-columns 2) и баланс скорости/качества (cpu-used 4).
- **GOP:** 30 кадров.
- **Аудио:** Перекодируется в libopus (битрейт 192 kbps, 48 кГц).

### HEVC (libx265)
- **Режим 1 (CRF):** Постоянный уровень качества (значение от 0 до 51, по умолчанию 23). Двухпроходное кодирование отключено.
- **Режим 2 (Целевой размер):** VBR (битрейт) с возможностью двухпрохода (через -x265-params pass=1/2).
- **Пресет:** medium (баланс скорости и эффективности).
- **GOP:** 30 кадров.
- **Аудио:** Копируется без перекодирования (copy).

## Установка

### Для пользователей Win10/11
Скачивать Python или FFmpeg отдельно **не нужно** — все зависимости уже встроены в установщик.

1. Перейдите в раздел [Releases](https://github.com/Gabymede/Transcode98/releases).
2. Скачайте файл `Transcode98_Setup.exe`.
3. Запустите установщик и следуйте инструкциям.

### Для пользователей Linux
Скачивать Python или FFmpeg не нужно, они уже внутри.

1. Перейдите в раздел [Releases](https://github.com/Gabymede/Transcode98/releases).
2. Скачайте файл `Transcode98_Linux_x86_64.tar.gz`.
3. Распакуйте архив в удобную папку:
   ```bash
   tar -xzf Transcode98_Linux_x86_64.tar.gz -C ~/Transcode98
   ```
4. Запустите приложение:
   ```bash
   cd ~/Transcode98
   ./Transcode98
   ```
